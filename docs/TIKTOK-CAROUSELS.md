# TikTok Carousels — Genetrify Beta Promotion

3 ready-to-shoot carousel scripts for driving waitlist signups from TikTok.

**Strategy:** Pre-render hero generations once, post them as carousels. Zero live-API burn during posting. Drives traffic to the waitlist (`genetrify.com`), not direct signup — beta is invite-only.

---

## Format conventions

- **Aspect ratio:** 9:16 vertical
- **Slide count:** 5–7 per carousel
- **Slide 1:** Pattern interrupt hook (must work in <2s autoplay preview)
- **Last slide:** Waitlist CTA
- **Caption text:** Bold, top-third of slide (survives autoplay crop)
- **Style:** Native-looking, not over-designed — black bottom bar + bold yellow/white text outperforms polished templates

## Execution notes

- **Slide 1 = everything.** TikTok cuts off carousel views in <2s if the first slide doesn't stop the scroll. Hook text must be in the top third so it survives the autoplay preview.
- **Use real generations from your studio** for the "after" slides — pre-rendered, no live API spend during posting. This is the whole "free TikTok content" strategy.
- **Don't over-design.** Bold text on actual generated images with minimal styling outperforms polished design templates because it looks native to TikTok, not like an ad.
- **Waitlist link** must be in your bio AND on the last slide. Don't expect people to type the URL from memory.
- **A/B test slide 1.** For each carousel, generate 2–3 variants of slide 1 with different hook text. Post one, watch performance, swap to the next if it underperforms.
- **Posting cadence:** 1 carousel per day for the first week. Avoid posting all 3 the same day — let the algorithm sample one before stacking.
- **Track conversion** by adding a `?ref=tiktok` query param to the bio link so you can see which carousels are driving signups in the waitlist admin table.

## Asset checklist before shooting

For each carousel you'll need pre-generated:

- **Carousel 1:** 1 product flatlay + 4 model generations (same product, different scenes) + 1 generated video
- **Carousel 2:** 1 hoodie flatlay + 4 hoodie-on-model generations (4 different scenes/styles)
- **Carousel 3:** 3–4 different model generations of the same product + 1 generated video

**Total burn:** ~12 image generations + 2 video generations, all done once from your own account.
